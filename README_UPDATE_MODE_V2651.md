# 시트 이동기 v2.6.5.1 — 기존 시트 업데이트 모드

이 패치는 **v2.6.4.2가 적용된 현재 프로젝트**를 기준으로 합니다.

## 변경 사항

- 메인 화면에 `기존 시트 이동 결과를 기준으로 변경사항 업데이트` 체크박스를 추가합니다.
- 체크하지 않으면 기존 초기 이동 경로와 동일하게 동작합니다.
- 체크하면 같은 D&D Beyond 캐릭터 ID + 같은 캐릭터 이름의 이전 `sheet-result`를 찾습니다.
- 이전 DDB raw와 현재 DDB raw를 비교하여 레벨/클래스/주문/장비 및 주요 구역 변동을 실행 로그에 기록합니다.
- 총 클래스 레벨이 증가하면 `probable_level_up`으로 기록합니다.
- 이전 결과에서 **영어 원문이 완전히 동일하고 검증을 다시 통과하는 번역만** 현재 번역기에 seed로 넣습니다.
- 새 원문 또는 변경된 원문은 기존 Google/Ollama 번역 경로를 그대로 사용합니다.
- 5e/5.5e처럼 이름이 같아도 설명 원문이 다르면 설명 번역을 서로 복사하지 않습니다.
- 이전 결과에서 동일 영어 원문에 서로 다른 번역이 존재하면 해당 원문은 재사용하지 않습니다.

## v2.6.5 실패에 대한 수정

- `SHEETMOVER_UPDATE_EXISTING` 환경변수 방식 제거: `update_existing` 명시적 인자로 전달합니다.
- `full_run.py`의 `os` 누락 문제 자체가 생기지 않도록 구조를 변경했습니다.
- UI 테스트용 객체에 `update_existing_var`가 없어도 기존 worker command가 정상 동작합니다.
- `hybrid_translator.py`를 **전혀 수정하지 않습니다.** 기존 cache-only 회귀 동작을 보존합니다.
- CLI 옵션은 기존 회귀 테스트가 찾을 수 있는 한 줄 형식으로 추가합니다.
- 기본 모드에서는 기존 함수 호출 형태를 그대로 유지하여 worker/full-run mock 호환성을 보존합니다.

## 안전 장치

설치기는 실제 프로젝트를 먼저 수정하지 않습니다.

1. 프로젝트 전체를 임시 복제합니다.
2. 복제본에만 패치를 적용합니다.
3. `sheet_mover` 전체 Python 컴파일 검증을 실행합니다.
4. `python -m unittest discover -s tests -q` 전체 테스트를 실행합니다.
5. 하나라도 실패하면 실제 프로젝트는 수정하지 않습니다.
6. 전부 통과했을 때만 실제 파일을 교체합니다.

또한 설치 중 `hybrid_translator.py`의 SHA-256이 바뀌면 즉시 중단합니다.

## 실행

ZIP의 내용을 `E:\sheet_mover`에 풀고 PowerShell에서:

```powershell
python apply_update_mode_v2651.py
```

성공 테스트의 개별 `... ok` 행은 출력하지 않습니다.
