# D&D Beyond → Roll20 sheet mover

브라우저의 D&D Beyond 캐릭터 데이터 응답을 수집하고, `qwen3.5:9b`로 텍스트를 번역하여 원본과 나란히 확인하는 Windows UI입니다. 번역 사전은 `glossary.json`에서 관리합니다.

**현재 단계는 미리보기입니다. Roll20 실제 입력은 구현되지 않았습니다.** 기존의 브라우저 변수 할당만으로 완료를 표시하던 코드는 제거했습니다.

## 실행

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

실행 진입점은 루트의 `main.py`입니다. `python -m sheet_mover --source https://www.dndbeyond.com/characters/170892133`으로도 같은 UI를 열 수 있습니다. `--cli`는 미리보기 결과 JSON을 출력하고, `--dry-run`은 설정만 출력합니다.

프로그램은 실행 중인 Chrome/Edge의 CDP(`http://127.0.0.1:9222`)에 연결합니다. 별도 브라우저를 설치·실행하지 않습니다. UI의 CDP 주소 또는 `ROLL20_CDP_URL`로 주소를 지정할 수 있습니다. 연결한 브라우저에 Roll20 캠페인(`/editor`)을 열고 D&D Beyond에 로그인해 두세요. 일반 브라우저 창만 열어두는 것으로는 CDP 연결이 되지 않습니다. Edge 실행 옵션은 UI의 'Edge 실행 방법'에서 확인할 수 있습니다.

## 확인 순서

1. 브라우저 '다시 확인'과 Ollama '상태 다시 확인'을 눌러 준비 상태를 확인합니다. Ollama 서버뿐 아니라 지정 모델의 설치 여부도 확인합니다.
2. '원본 수집 · 번역 미리보기'를 누릅니다. 원본 URL과 같은 ID의 캐릭터 응답을 기다립니다. 로그인 등으로 실패하면 새 D&D Beyond 탭을 남깁니다.
3. 미리보기의 확인 사항, 능력치/HP, 숙련, 장비, 주문, 특성을 원본과 대조합니다.
4. '원본·번역 JSON 저장'으로 원본 응답과 정리된 데이터, 번역, 미확인 사항을 함께 저장합니다. 저장된 파일에는 `applied: false`가 명시됩니다.

캐릭터 이름·원본 항목명·ID·숫자·내부 코드는 번역 대상에서 제외합니다. 항목명·설명·주문 재료 설명·숙련 텍스트는 사전과 모델을 이용해 번역합니다. 번역 요청 실패, 빈 응답, 숫자·주사위식·HTML 변경은 오류로 표시합니다.

## 남은 구현과 한계

- 현재 D&D Beyond 수집기와 데이터 필드 대응은 실제 브라우저에서 검증하지 않았습니다. 응답 URL/구조 변경 시 수정이 필요합니다.
- 최종 능력치의 조건부 보정과 기본 HP 기반 계산은 미지원입니다. 확인할 수 없는 값은 `null`로 표시하고 원본 응답을 보관합니다.
- 주문·특성의 조건부 활성화, 선택 옵션, 커스텀 항목, 부여 원인별 중복 판정은 미지원입니다. 원본 목록의 완전성과 적용 여부는 대조가 필요합니다.
- 다음 단계: Roll20 2014 시트 필드 매핑, 동명 캐릭터 탐색/중복 경고, 반복 항목 유지·추가, 단일 값 교체 및 저장 결과 재확인.
- 여러 Roll20 캠페인 탭은 미리보기에 모두 표시합니다. 현재 대상 캐릭터를 선택하거나 수정하지 않습니다.
