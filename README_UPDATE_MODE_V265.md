# 시트 이동기 v2.6.5 — 기존 시트 업데이트 모드

- 메인 화면에 `기존 시트 이동 결과를 기준으로 변경사항 업데이트` 체크박스를 추가합니다.
- 체크 시 같은 D&D Beyond 캐릭터 ID + 같은 캐릭터 이름의 이전 성공 결과만 업데이트 기준으로 사용합니다.
- 이전 raw DDB와 현재 raw DDB를 비교해 총 레벨 변화, 클래스 변화, 주문/장비 추가·삭제, 변경 구역을 기록합니다.
- 레벨이 증가하면 `probable_level_up`으로 기록합니다. 추측 결과는 보고용이며 규칙 수치를 임의 생성하지 않습니다.
- 이전 결과에서 검증된 **동일 원문 문자열의 번역**은 새 실행에서 seed로 재사용합니다. 새로 생기거나 원문이 바뀐 문자열만 기존 Google/Ollama 경로로 갑니다.
- 같은 이름이더라도 D&D Beyond 캐릭터 ID가 다르면 업데이트하지 않습니다.
- Roll20 언어/비기술 숙련은 현재 live 시트에 정상 입력되는 것으로 보고 별도 표시 수정은 하지 않습니다. PDF 인쇄 결과와 live sheet 표시를 동일시하지 않습니다.
- 실제 프로젝트를 수정하기 전에 복제본 전체 unittest를 `-q`로 실행합니다. 성공 테스트의 `... ok`는 출력하지 않습니다.
